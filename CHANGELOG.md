# Changelog

## Unreleased (следующая версия после 1.1.3)
- Диагностика и рефакторинг по независимому ревью.
- Сессии захвата пронумерованы (`captureSession`): поздние ответы DOM/SVG больше не переключают режим и не закрывают следующую сессию.
- Один выход `finishCapture()`: фокус возвращается сразу, а не после распознавания (раньше поздний OCR мог отнять фокус у новой сессии и закрыть её), полноэкранные скриншоты освобождаются после HEX/DOM/SVG, SVG не держит Tab/Esc перехваченными, пока работает AppleScript.
- Тройной ⌘⇧1 больше не даёт ложный аварийный выход (эвристика считала «Quirky не активен» признаком зависания).
- Таймеры оверлея гасятся при закрытии; удаление SPX-отрезка отменяет анимацию, которая писала в него по индексу.
- HEX считается в sRGB (раньше захват P3-экрана подписывался как sRGB без конвертации).
- AppleScript DOM/SVG идёт через одну последовательную очередь (NSAppleScript не потокобезопасен).
- Убран мёртвый код: цепочка «спрятать SPX с сохранением», `onSPXSizePicked`, `ScreenCapture.swift`, функции Accessibility, дубль запуска режимов (`showFor*`), старт сессии теперь идёт через тот же `switchActiveCaptureMode`.
- Магазинная версия: убраны неиспользуемые права `network.client` и `files.user-selected.read-write`, в песочнице только сама песочница.

## 1.1.3 (build 9) — 24.10.2026, Mac App Store
- OCR «ничего не копирует»: (1) первый клик по оверлею съедался активацией окна, когда macOS не делала Quirky активным, выделение начиналось без mouseDown и молча терялось; теперь `acceptsFirstMouse`. (2) Модель Vision `.accurate` на занятом маке грузилась 30–70 с, ошибки глотались и в буфер уходила пустота. Теперь прогрев при запуске, каждые 4 минуты и при ⌘⇧1; при ошибке точного режима запасной быстрый; тост «Recognizing…»; ошибки в лог.
- Лог захвата: `/usr/bin/log show --predicate 'subsystem == "com.threempq.quirky"'` (в zsh `log` перехватывает встроенная команда, звать по полному пути).
- `Scripts/build.sh` подписывает из связки login.
- Первая сборка для Mac App Store: OCR, HEX, SPX; бесплатно. Исправлено: магазинный бинарник ссылался на вырезанный Sparkle и упал бы при запуске (`-dead_strip_dylibs`).
- Фаза вырезания Sparkle переподписывает с `$OTHER_CODE_SIGN_FLAGS` (подпись из связки login).
- `ITSAppUsesNonExemptEncryption = NO` в Info-MAS.plist.
- Оверлей: скриншот композитится GPU как `layer.contents`, HUD рисуется в отдельном подслое; таймер пунктира перерисовывает только когда пунктир на экране; HEX читает пиксели из кэша вместо полного рендера на каждое движение мыши. Замер на M3 Pro: CPU на кадр 0,3–2 мс до и после, заметного лага не было.
- Документация: AGENTS.md, docs/, changelog.
