## Подтверждённые причины и исправления

1. **Nothing не распознавался.** В обоих прежних списках не было `com.3mpq.nothing`.
   Списки и генератор AppleScript объединены в `Quirky/BrowserAutomation.swift`; Nothing добавлен.
   `DOMExtractor` и `SVGExtractor` используют один источник истины. Chromium адресуется по bundle id,
   без зависимости от локализованного имени приложения. Поиск `ai.perplexity.comet` в `Quirky/`
   теперь находит единственный общий список.

2. **JavaScript выключен.** Без изменения настроек выполнена предоставленная команда:

   ```bash
   osascript -e 'tell application "Nothing" to tell active tab of front window to execute javascript "1+1"'
   ```

   Получен exit 1, AppleScript **12**:
   `Executing JavaScript through AppleScript is turned off.`
   Раньше DOM и SVG scan превращали эту ошибку в `[]`, а SVG extraction логировал сырой словарь
   и тоже возвращал `[]`. Теперь ошибка классифицируется, возвращается в `AppDelegate` и показывает:
   **«Включите в браузере View > Developer > Allow JavaScript from Apple Events»**.
   Путь общий для Chromium. Safari получает отдельную подсказку о меню Develop / настройках
   разработчика; современный интерфейс описан в [документации Apple](https://developer.apple.com/documentation/safari-developer-tools/developer-settings).
   При ошибке сканирования сессия штатно завершается и оверлей закрывается,
   поэтому ошибка не оставляет пользователя перед пустым выбором.

3. **Automation и другие ошибки.** `-1743` / `-10004` дают тост с путём
   `System Settings > Privacy & Security > Automation` и именем Quirky.
   `-1728` предлагает открыть окно с вкладкой. Остальные ошибки AppleScript дают сообщение с кодом.
   Некорректный JSON и недоступная область страницы также имеют отдельные исходы.
   Корректный `[]` не считается ошибкой AppleScript: DOM сообщает об отсутствии элементов,
   SVG extraction сохраняет `No SVGs found`.

4. **Скрытая запись настроек.** `detectBrowser` раньше запускал `defaults write` для включения
   JavaScript в Chromium и Safari. Эти вызовы убраны из обоих экстракторов. Распознавание теперь
   только читает bundle id. Пользователь сам включает настройку; изменение в запущенном браузере
   не пытаемся имитировать записью preferences.

5. **Поздний SVG extraction.** В отличие от SVG scan, финальное извлечение не проверяло сессию
   и могло перезаписать буфер/тост после начала следующего захвата. Добавлена проверка номера
   сессии, текущего режима и завершённости захвата. Фокус из callback не меняется.
   Слои защиты от залипшего оверлея не удалялись.

## Новая диагностика, без контента

`Quirky/BrowserAutomation.swift` пишет событие `browser_operation` для `dom_scan`, `svg_scan`,
`svg_extract` — в том числе для неподдерживаемого приложения, ошибок, пустых и успешных результатов.

Поля `data`: `mode`, `operation`, `browser_bundle_id`, `status` (`success`/`empty`/`error`),
`duration_ms`, `result_count`; при ошибке — `error_kind`, при наличии — `applescript_error_code`.
Длительность измеряется монотонными часами и включает ожидание общей очереди AppleScript и подготовку
операции; это полная длительность операции, не отдельно время выполнения JS.

Envelope: `app=Quirky`, `type=browser_operation`, версия/билд, timestamp, случайные session/install id,
порядковый номер события. Install id создаётся только при наличии конфигурации отправки.
Строки ошибок AppleScript используются локально для классификации и никуда не записываются целиком.
Не отправляются текст OCR, селекторы DOM, SVG, заголовки, адреса страниц, скрипты, буфер или скриншоты.

- Локально: OSLog, subsystem `com.threempq.quirky`, category `browser`, независимо от сетевой конфигурации.
- Direct: отправка на существующий `/e` по HTTPS, только с endpoint и ingest key в собранном `.app`.
  `Scripts/build.sh` добавляет конфигурацию при экспортированном `APPS_TELEMETRY_INGEST_KEY` и затем
  переподписывает итоговый bundle. Dashboard token приложению не передаётся.
- Без ключа: только локальные события, без сетевых запросов.
- MAS: весь новый Swift-код исключён через `#if !MAS_BUILD`; endpoint/key не добавляются в `.app`.
- Доставка best effort: нет дисковой очереди/повторов. Ошибка доставки отражается локально без тела запроса.
  Это диагностика DOM/SVG, а не полный SDK usage/crash reporting для всех режимов.

Обновлён `docs/05-setup.md` с командой сборки и границами диагностики.
