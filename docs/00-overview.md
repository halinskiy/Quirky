# Обзор

Quirky живёт в меню-баре. ⌘⇧1 замораживает экран скриншотом и открывает оверлей в последнем
использованном режиме (`lastCaptureMode`). Результат уходит в буфер обмена.

| Режим | Что делает |
|---|---|
| OCR | Vision-распознавание текста в выделении или по клику на слово |
| HEX | пипетка цвета под курсором |
| DOM | выбор DOM-элемента в Safari/Chrome/Arc/Brave/Edge/Comet/Vivaldi/Opera (Apple Events) |
| SPX | пиксельные измерения в духе PixelSnap, работает вместе с другими режимами |

Управление: ЛКМ по иконке = поповер с режимами, ПКМ = настройки. Tab / ⇧Tab листают режимы,
Esc выходит всегда, ⌘⇧1 в SPX включает ghost (экран живой, разметка поверх).
