# Управление

- ⌘⇧1 — захват в последнем режиме и поповер под иконкой. Три нажатия за секунду при залипшем оверлее = аварийный выход.
- Tab / ⇧Tab — следующий / предыдущий режим. DOM без браузера впереди пропускается в сторону движения.
- Esc — выход из любого режима.
- SPX: H/V фиксируют отрезок, Shift = лучи без препятствий на весь экран, ⌘⇧1 = ghost.
  Толерантность Window / Element / Detail (`spxToleranceLevel`).
- ПКМ по иконке: тумблеры режимов, цвет подсветки, Check for Updates, Quit.
